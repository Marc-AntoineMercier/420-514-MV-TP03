# 420-514-MV-TP03

for clone with lfs you have to use the command bellow

````bash
git clone https://github.com/Marc-AntoineMercier/420-514-MV-TP03.git
git lfs checkout
````

si ne fonctionne pas

````bash
git clone https://github.com/Marc-AntoineMercier/420-514-MV-TP03.git
git lfs pull
````

for run the project we have to run

````bash
make install
make run
````
