## Éxecution du projet

### 1. Étape

Cloner le repository avec cette commande.

````bash
git clone https://github.com/Marc-AntoineMercier/420-514-MV-TP03.git
````

### 2. Étape

Chercher les données avec git large file

````bash
git lfs checkout
````

si ne fonctionne pas utiliser

````bash
git lfs pull
````

### 3. Étape

Pour rouler le projet utiliser ces commandes.

````bash
make install
make run
````
